# CivicAlert - Online Complaint Registration System
A full stack MERN application for filing and managing civic complaints.
## Tech Stack
- Frontend: React+Vite
- Backend: Node.js+Express.js
- Database: MongoDB+Mongoose
- Authentication: JSON Web Tokens(JWT)
## Roles
- **Citizen** - Files and tracks complaints
- **Agent** - Manage and resolve assigned complaints
- **Admin** - Approve agents and assign complaints
## Setup Instructions

### Backend
cd server
npm install
npm run dev

### Frontend
cd client
npm install
npm run dev
